# 答辩代码导读（滑坡识别系统）

> 核心 Java/Vue 文件已补充中文注释，答辩前按本表过一遍即可。

## 一、业务流程（建议背诵）

1. 用户 **登录** → `UserAuthController` 校验密码 → `JwtTokenService` 签发 Token  
2. 前端 **上传图片** → `DetectTaskView` → `POST /api/detect/image`  
3. **YOLO 推理** → `YoloDetector.detect()` 返回检测框  
4. **灾情评估** → `DisasterLevelServiceImpl` 算面积/等级/是否预警 → 写 `landslide_detect_record`  
5. **I/II 级预警** → `WarningPushServiceImpl` 写 `warning_event` + WebSocket 推送  
6. **灾情动态页** → `DisasterFeedView` 列表展示 + 工作人员确认

## 五、答辩常问

**Q：为什么用 YOLO？**  
A：单阶段检测，速度快，适合遥感/航拍滑坡目标；导出 ONNX 后 Java+OpenCV 部署无需 Python 推理。

**Q：等级怎么定的？**  
A：检测框像素面积累加 + 最大置信度，与阈值比较得 I~IV 级（见 `classifyDisasterLevel`）。

**Q：预警怎么实时？**  
A：后端 `SimpMessagingTemplate` 推 STOMP 主题，前端 SockJS 订阅刷新列表。

**Q：Token 怎么用？**  
A：登录返回 JWT，前端 `request.js` 每次请求带 `Authorization: Bearer`，过滤器解析后注入 SecurityContext。
